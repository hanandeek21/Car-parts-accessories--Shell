# Car Parts & Accessories - Microfrontend Shell

This project acts as the **Application Shell** for Group 14's E-Commerce store. It integrates various micro-frontend components developed by team members using different frameworks (Vue, React, and others) into a single, unified interface.

## Team Members & Components
| Name | Role | Framework |
| :--- | :--- | :--- |
| **Hanan** | Catalog & Discovery | Vue 3 |
| **Mohammad** | Cart & Checkout | React/Netlify |
| **Yahya** | Account & Orders | React |

## Architecture
- **Integration Method:** Iframes-based Microfrontend architecture.
- **Deployment:** Vercel, Netlify, etc.
