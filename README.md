# Car Parts & Accessories - Microfrontend Shell

This project acts as the **Application Shell** for Group 14's E-Commerce store. It integrates various micro-frontend components developed by team members using different frameworks and deployment platforms into a single, unified interface.

## Team Members & Components
| Name | Role | Framework | Hosting Platform |
| :--- | :--- | :--- | :--- |
| **Hanan** | Catalog & Discovery | Vue 3 | Vercel |
| **Mohammad** | Cart & Checkout | React | Netlify |
| **Yahya** | Account & Orders | React | Independent |

## Architecture
- **Integration Method:** Iframe-based Microfrontend architecture.
- **Deployment Strategy:** 
    - **Application Shell:** Deployed and hosted on **Vercel**.
    - **Micro-frontend Components:** Independently developed and deployed by each team member using their preferred hosting platform (e.g., Vercel, Netlify).
